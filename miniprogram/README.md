# 余生有刻微信小程序

“余生有刻”是 LifeScale 旗下的原生微信小程序，口号为“看见余生，认真今天”。它复用 `app.lifescale.space` 的 Supabase 用户、邮箱验证码、人生刻度、每日记录和 7 天报告数据。

## 微信平台资料

- 小程序简称：`余生有刻`
- 英文品牌：`LifeScale`

- 品牌口号：`看见余生，认真今天。`

## 1.2.0 多图记录（2026-09-07）

- 网页多选图片，小程序每次可选 9 张并可继续添加；保存前可逐张移除，记录中点图可查看整组相册。
- 不再按原文件 10 MB 拒绝选择。大图提示处理/上传较慢，在本机转为最长边不超过 2560px、5 MB 内的静态 JPEG，然后上传私有存储。未改变原文件，云端保存优化后的副本。设备仍有解码与内存限制，失败时明确提示，不承诺无限大小。
- 网页接受 JPG、PNG、WebP、GIF、AVIF、BMP；HEIC/HEIF 取决于设备解码支持。小程序相册格式由设备决定。动图取单帧，透明区域变为白色，移除源图片元数据。
- 记录与每张照片使用稳定 ID；失败后重试当前窗口的剩余上传，已完成照片不重复上传。关闭页面不会保留尚未上传的本机选择。
- 网页与小程序共用排版引擎。图文分开采用完整、不裁切的相册排版；文字镶嵌可选择背景，多个照片时整组相册保留在文字后。通常一张长图，超过 7200px 自动完整分页；每页可选择保存/分享，不截断文字或漏图。
- 保留微信内长按保存/发送和小程序原生图片分享；不创建公开记录，不自动发布到任何社交平台。
