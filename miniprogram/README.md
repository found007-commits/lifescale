# 余生有刻微信小程序

“余生有刻”是 LifeScale 旗下的原生微信小程序，口号为“看见余生，认真今天”。它复用 `app.lifescale.space` 的 Supabase 用户、邮箱验证码、人生刻度、每日记录和 7 天报告数据。

## 微信平台资料

- 小程序名称：`余生有刻`
- 小程序简称：`余生有刻`
- 英文品牌：`LifeScale`
- 产品介绍：`余生有刻是 LifeScale 旗下的生命时间记录产品，帮助用户看见人生进度、记录每个值得留下的今天，并逐步建立属于自己的人生档案。`
- 品牌口号：`看见余生，认真今天。`

## 打开方式

1. 在微信开发者工具选择“导入项目”。
2. 目录选择本仓库的 `miniprogram` 文件夹。
3. 项目已配置正式小程序 AppID：`wxa1ad4ff408b7727d`。
4. 在微信公众平台配置 request 合法域名：
   - `https://app.lifescale.space`
   - `https://utcgiopwbfcmnryerynr.supabase.co`
5. uploadFile 和 downloadFile 合法域名均需配置上述 Supabase 域名。开发及发布均保留合法域名校验。

## 登录方式

仅提供邮箱六位验证码登录，不设置密码，也不接入微信、Google、Apple 或 Facebook 登录。

## 发布前仍需要

- 已配置正式小程序 AppID：`wxa1ad4ff408b7727d`。
- 在公众平台填写隐私保护指引。
- 完成小程序备案、类目和版本审核。
- 配置上述两个服务器域名。

## 1.1.0（2026-09-07）

- 原生「记录 → 分享」和首页最近记录的分享入口。
- 图文分开、文字镶嵌；后者使用深色底板保证对比度。
- 普通长记录生成完整长图；超过单图安全高度 7200px 时完整分页，不截断文字。预览独立滚动，操作按钮不会被长图推到底部。
- 通过 `wx.showShareImageMenu` 打开微信原生图片分享菜单；朋友圈选项取决于微信版本和平台支持。旧版本可长按图片或保存后发送，不跳外部浏览器。
- 相册保存后可由用户自行发布到 Facebook、Instagram 等平台；没有自动跨平台发布。
- 分享卡仅在本机生成，事件通道传递选中的记录，不创建公开记录或公开详情链接。图片分享附带的小程序入口固定为首页。关闭分享页后清理本页生成的临时图片。
- 同步邮箱验证码登录、会话自动刷新、性别选项、语言及显示偏好、永久核心目标确认、首日/百日提醒和数据导出。
- 新用户按 IP 选择简中/繁中/英文，已保存的语言优先。可运行 `node scripts/build-mini-locales.mjs` 重新生成产品文案字典；不翻译用户自己写的记录。
