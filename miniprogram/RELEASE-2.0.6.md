# 2.0.6 — 启动与页面切换性能

2026-09-16

## 改动

- 新增 `/api/miniprogram/service-config`：仅返回公开连接配置，构建时静态生成，每小时重新验证。旧 `/config` 保留以兼容旧版；私密记录及认证接口不做公共缓存。
- 小程序改用静态配置接口；保留域名校验、请求合并与公开配置 24 小时本地缓存、后台刷新。语言沿用设备/已缓存设置与个人偏好，不再依赖配置接口按 IP 判断。
- 今天、历史、小回顾页面在同一账号、同一天、30 秒内复用页面内存数据；下拉刷新、记录/资料修改、删除、留言和退出登录使数据重新读取。不将记录写入新的持久化缓存。
- 切换账号或后续请求完成后，较早的请求不能覆盖当前页面；个人资料异步返回也验证当前账号。
- 小回顾只请求日期、心情和分类等统计字段，不拉媒体附件、不申请照片签名地址。
- 相同语言标签不再重复 setData；导航栏去重同时区分页面实例。
- 保留已有的会话内存缓存、照片签名批处理/内存缓存、图片懒加载、视频/GIF 按需加载，以及开发文档不参与打包。

## 验证

- 166 项自动测试通过；全量 ESLint、小程序 ESLint、TypeScript 和生产构建通过。
- 新测试覆盖页面复用、30 秒到期、跨天、账号切换、退出登录、修改失效、下拉刷新、失败重试、旧请求竞态、小回顾不签名媒体，以及不重复写入语言标签。
- Vercel 生产环境候选构建确认新接口为静态路由；候选接口 HTTP 200，`x-vercel-cache: PRERENDER`，响应严格只有公开服务地址和 publishable key。
- 没有用真实用户记录进行删除或编辑测试；没有修改数据库权限或用户数据。

## 边界

- 30 秒内其他设备的修改可能暂未出现，可下拉刷新。
