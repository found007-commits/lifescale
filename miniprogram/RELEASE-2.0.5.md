# 2.0.5 — 删除修复与浏览请求优化

2026-09-15

## 删除

- 保留工作区已有的修复：Storage 删除使用桶对象端点与 `{ prefixes: [...] }` JSON 请求体，避免空 JSON 请求触发解析错误。无请求体的普通请求不再显式声明 JSON 类型。
- 验证当前账号与记录所有者、媒体路径归属；先删除媒体再删除记录。存储失败时保留记录及引用，支持重试；不承诺跨存储/数据库事务回滚。
- 测试覆盖纯文字、图片/视频/GIF、重复路径、错误账号、存储失败、响应丢失和记录删除失败后的重试。
- 未以用户真实记录执行删除。

## 浏览

- 图片访问地址按最多 100 个路径批量获取；视频/GIF 仍点开才加载。批量失败不丢弃附件，可在详情/分享中重试。
- 图片地址最多缓存 256 项，仅在内存保存 50 分钟，按服务与账号隔离，退出登录清空；列表内容仍通过带权限校验的接口重新获取。
- 公开服务配置仅缓存白名单字段 1 小时，限定服务域名，后台刷新；不缓存用户记录、会话或失败结果。
- 人生刻度先渲染，最近记录随后加载；返回已加载列表保留当前画面，切换账号清空上一账号画面。
- 自动测试中 20 张照片首次列表请求由 21 次降到 2 次，再次读取同一批只需列表请求。此为请求数对比，不是实际网络提速倍数。

## 提审前真机验收

1. 使用未登录设备首次打开，确认仍可先体验。
2. 自行创建一条可丢弃的文字/影像测试记录，确认取消删除无变化、确认删除成功。
3. 首次进入历史与再次返回列表，对比加载感受；图片、视频和 GIF 均可打开。
4. 切换账号后，确认不显示前一账号记录。
