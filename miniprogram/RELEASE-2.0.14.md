## 三处真正修掉的缺陷

### 1. 回复预览：浅字压浅底，等于看不见（`entry.wxss`）

`.reply-preview` 里那行 `<text>` 没有颜色类，深色下**继承 `page` 的 `#edf3ef`**；而底是写死的 `#e3ece3`。

| 组合 | 对比度 | 判定 |
|---|---|---|
| `#edf3ef` 在 `#e3ece3` 上（深色下实际发生的） | **1.07:1** | ❌ 文字不可见 |
| `#123f31` 在 `#e3ece3` 上（浅色下正常） | 9.75:1 | ✅ |
| `#edf3ef` 在 `#0f1c17` 上（改后） | **15.57:1** | ✅ |

改法是加一条深色覆盖，底色复用**旧调色板自己的深色页底** `#0f1c17`——它在 `#192a22` 的卡片上读作一个**凹槽**，与浅色下 `#e3ece3` 在 `#fbfaf6` 卡片上的关系对称（1.16:1 对 1.22:1），**不新造颜色**。

### 2. 分隔线：同一根线在两种底色上是两样东西（`entry.wxss`）

`.comment` 与 `.edit-panel` 的 `#c7d1ca` 在浅色纸上是**刻意做的柔和细线**（1.36:1），在深色纸上变成 **11.18:1** 的刺眼亮线。

改后是 `rgba(237, 243, 239, .12)`，与 `app.wxss` 深色块里 `.paper-card` 用同一条边界色，落在 **1.42:1** —— 几乎是浅色那一侧的同等柔度。

### 3. 覆盖不是错色，是**死代码**（`app.wxss`）—— 这一处最值得记住

`app.wxss` 里 `.media-placeholder` 被声明了**两次**：

```css
@media (prefers-color-scheme: dark) {
  ...
  .media-placeholder { background: #192a22; color: #91a69b; }   /* 意图：深色下换深底 */
}
/* Heavy media is deliberately absent from list src attributes until opened. */
.media-placeholder { ...background: #e3ece3; color: #123f31; }  /* ← 却排在媒体查询之后 */
```

两条规则**权重完全相同**（都只有一个类选择器），于是**后面的赢**——深色块里那条覆盖从来没生效过。深色下会浮出一块 `#e3ece3` 的浅色板子（与页底 14.49:1）。

**为什么难发现**：它不报错、不空白。板子里的文字 `#123f31` 在 `#e3ece3` 上是 9.75:1，**可读**，所以任何只查可读性的检查都会放它过去。它坏的是「页面不该在深色下有一块发白的板子」，而这只有看渲染结果或读源码顺序才知道。

改法是**把基础规则移到媒体查询之前**，让原本写在里面的覆盖按作者本意生效（`#91a69b` 在 `#192a22` 上是 5.83:1）。不重设计、不换颜色。

> 注意：`record` 页用的是 `.ui-207 .media-placeholder`（权重更高），一直是对的。**只有 `entry` 页**（不走 `.ui-207`）受这个顺序问题影响。

## 一条比这三处缺陷更重要的发现：推版本号会**静默关掉**上一版的测试

写完代码跑全量，跳过的测试从 **84 涨到 95**。原因是这个仓库的测试按 `version === 'x.y.z'` 门控，**读的是 `miniprogram/package.json`**——把版本推到 2.0.14，2.0.13 的全部 11 项测试立刻不跑了。

原本记录的应对是「建新基线」，但那**只覆盖 `protectedFiles` + `markup` 两类**。行为类不变量（比如「主题脚本必须渲染在 `<head>` 内」「初始化脚本与 `useTheme` 读同一个存储键」「政策不得再出现被撤回的承诺」）**不在基线里**，会随版本号一起消失。

数字摆在眼前：

```
门控把 2.0.13 的 11 项关掉，其中 5 项是描述线上应用的不变量
2.0.12 早已被 2.0.13 的版本号关掉 6 项同类（含「撤回的承诺不得复活」）
```

本版的处置：把**描述线上应用**的 11 项解开（去掉 `{skip: !release}`，标题里的版本号也去掉，它们不是「本版干了什么」而是「这个应用必须一直是怎样」），只保留描述 **本版 diff** 的门控（改了哪几个文件、日期、版本号本身）。

结果：全量 **311 项 / 227 通过 / 0 失败 / 84 跳过** —— 跳过数回到与 2.0.13 持平，覆盖补齐后还多了 10 项。

**给下一版的提醒**：推版本号时，除了建新基线，还要检查上一版测试里有哪些是**不变量**而非 **diff**，把前者解开。

## 本版没有做的

- **小程序旧五页配色迁移**：你选的是「只修客观缺陷」，不迁移调色板。浅色模式**逐字节未动**。
- **tribute 致意的访客视角验收**：你选暂不做，仍是已知未验证项。
- **实机渲染确认**：小程序模拟器**没有可靠手段触发系统深色偏好**，所以本版的深色结论来自 **CSS 级联推算 + 对比度算术**，不是渲染截图。这一点在报告里始终被标注。
